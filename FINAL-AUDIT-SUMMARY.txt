PHYSICAL LEDGER MODEL
========================================
Identity: location + SKU + batch + expiry
         (NOT binId which omits expiry)

Event ordering: numeric wave, relocations before picks

Balance calculation:
  balance = initial
  for each event (chronological):
    if RELOC: balance += qty
    if PICK:  balance -= qty
              line.qtyRemainingInBin = balance

Accounting:
  Customer picks: outbound to staging
  Internal relocations: source → pickface (not subtracted from customer outbound)
